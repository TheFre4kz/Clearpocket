# Clearpocket

Meine persönliche Finanz-App: Einnahmen, Ausgaben, Fixkosten, Sparen und Prognose –
als Web-App fürs iPhone.

- Alle Daten bleiben **nur auf meinem Gerät** (im Browser gespeichert).
- Kein Tracking, keine externen Dienste.
- Gebaut mit reinem HTML, CSS und JavaScript.

Den ausführlichen Plan und den aktuellen Stand findest du in [PROJEKTPLAN.md](PROJEKTPLAN.md).
